Apps using 7.1

  1. Click Choose apps… (Windows "App volume and device preferences").
  2. Start the game or player, then set its Output to CABLE Input (VB-Audio Virtual Cable).
  3. In the game, pick 7.1 or Surround / Home theater speakers if it asks.

Checks

Measure a Dolby Access mode

  1. Set the headphones' Spatial sound to Dolby Atmos for Headphones.
  2. In Dolby Access, pick the same profile and Intelligent EQ as below.
  3. Stop music/video and don't touch the volume for about 90 seconds.

HeSuVi is bypassed while measuring so only Dolby is recorded. The result becomes a new mode in the list.
